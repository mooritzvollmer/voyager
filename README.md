# Voyager 1

Eine kleine interaktive Visualisierung der Voyager-1-Mission mit berechneter Entfernung, Signallaufzeit, Missionsdauer und Flugrichtung.

**Live:** [voyager.moritzvollmer.de](https://voyager.moritzvollmer.de/)

## Daten und Darstellung

- Fortschreibung einer NASA/JPL-Horizons-Referenz
- Entfernung zur Erde in Kilometern und astronomischen Einheiten
- einfache und doppelte Signallaufzeit
- Missionszeit seit dem Start am 5. September 1977
- responsive animierte Sondenillustration

Die aktuellen Werte sind Näherungen auf Basis der dokumentierten Referenz und keine Live-Telemetrie.

## Technische Basis

Vue 3, JavaScript, CSS und Vite.

```sh
npm install
npm run dev
npm run build
```
